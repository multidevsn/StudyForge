# ECLYRIA — Echoes of the Fallen

Prototype 0.1 — third-person fantasy open-world foundation.

This repository was cleaned before construction. No previous StudyForge assets are used by the game.

The prototype is asset-free: terrain, vegetation, rocks, ruins, water, lighting and the player are generated with Godot primitives at runtime.

## Controls
W/A/S/D move · Shift sprint · Space jump · Mouse camera · Left click attack · Esc release mouse

External assets will be added later only from explicitly selected free/CC0 sources, with attribution and license records.

See docs/ROADMAP.md.
