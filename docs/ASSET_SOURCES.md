# ECLYRIA Asset Sources

The repository is intentionally independent from its previous contents.

## Selected external sources

### Quaternius
Use for stylized characters, nature, medieval buildings, fantasy props and humanoid animations.
- Official library: https://quaternius.com/
- Current relevant packs include Stylized Nature MegaKit, Medieval Village MegaKit, Fantasy Props MegaKit, Universal Base Characters and Universal Animation Library.
- Quaternius lists these packs as CC0/free for personal and commercial projects.

### Poly Haven
Use selectively for high-quality PBR materials, rocks/props and HDRIs.
- https://polyhaven.com/
- Assets are CC0.
- The live API is free for commercial use; if ECLYRIA uses the API directly, follow Poly Haven's API credit requirement.

## Integration rule

Do not copy random assets from the web.

Every imported asset must:
1. come from an explicitly selected source;
2. have its license recorded here;
3. be placed under assets/external/<source>/;
4. have a stable source URL recorded;
5. be checked for Godot 4 compatibility;
6. be optimized before use in the open world.

## First asset pass

1. Stylized Nature — trees, rocks, grass and plants
2. Medieval Village — houses, walls, market and village props
3. Universal Base Character — player foundation
4. Universal Animation Library — locomotion/combat animations
5. Fantasy Props — weapons, chests, furniture and interactive objects
6. Poly Haven — selected terrain/PBR materials and HDRI lighting

No asset from the old StudyForge project is used.
