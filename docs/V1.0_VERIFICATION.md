# ECLYRIA V1.0 — Vérification

## Monde ouvert
- [x] Terrain central compatible avec une grille de régions de 80 m.
- [x] Coordonnées mondiales continues.
- [x] Régions adjacentes générées avec la même fonction de hauteur afin de rester raccordées.

## Streaming des régions
- [x] Region.tscn.
- [x] RegionStreamer.
- [x] ResourceLoader.load_threaded_request() pour le chargement asynchrone de la scène de région.
- [x] Grille active 3×3 autour du joueur : zone centrale + 8 régions streamées.
- [x] Déchargement automatique des régions hors rayon.
- [x] Régions découvertes sérialisées dans la sauvegarde.

## Optimisation
- [x] Renderer GL Compatibility conservé pour les machines modestes.
- [x] Résolution de terrain central réduite pour limiter le coût initial.
- [x] Régions secondaires moins détaillées.
- [x] Distance de visibilité sur les arbres/rochers.
- [x] Culling périodique des objets du groupe stream_optimized.
- [x] Limite cible à 60 FPS.

Les plages de visibilité/LOD sont cohérentes avec les recommandations de Godot pour réduire le coût du rendu 3D à distance.

## Audio
- [x] Gestionnaire audio global.
- [x] Ambiance musicale procédurale.

## Limite de vérification
Le runtime Godot n'a pas été exécuté dans cet environnement. Le dépôt est donc vérifié par inspection des scripts/scènes et cohérence des références, mais la validation finale FPS/erreurs/runtime doit être faite avec Godot 4.x.
