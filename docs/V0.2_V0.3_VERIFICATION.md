## Limites connues
- Les modèles 3D professionnels Quaternius/Poly Haven ne sont pas des binaires importés par cette étape.
- Le donjon V0.3 est une première version procédurale.
- Le marchand utilise une interaction clavier minimale plutôt qu'une boutique UI complète.
- Les événements sont des événements de gameplay simples et non un système de calendrier persistant.

## Critère de vérification
Une fonctionnalité est cochée uniquement si elle existe dans le code du dépôt et est reliée au gameplay principal.
